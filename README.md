# LM Studio — Portfólio de conversão

Site estático, responsivo e sem dependências de build.

## Arquivos
- `index.html` — estrutura e copy
- `styles.css` — direção visual e responsividade
- `script.js` — menu mobile, header e pequenas animações
- `assets/lm-logo.png` — logo enviado no projeto

## Publicação
Pode ser publicado diretamente em Netlify, Vercel, GitHub Pages ou qualquer hospedagem de arquivos estáticos.

## Antes de publicar
1. Troque os links de CTA caso queira usar WhatsApp, e-mail ou formulário em vez do LinkedIn.
2. Substitua as demonstrações conceituais pelos seus cases reais quando tiver imagens autorizadas.
3. Adicione domínio e imagem Open Graph absoluta quando souber a URL final.
4. Revise o texto do FAQ conforme o seu processo comercial real.

## Direção de design
A paleta parte do logo: papel/off-white, tinta quase preta e aqua como acento. A estrutura é editorial e deliberadamente evita um portfólio genérico de cards arredondados. O foco da copy é venda por clareza e percepção, sem inventar métricas, clientes ou depoimentos.
